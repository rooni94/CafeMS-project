# Cafe Management System (Skeleton)

This repository is a ready-to-use skeleton for a Cafe Management System:
- Backend: Django + DRF + SimpleJWT + Channels (Redis) + Stripe skeleton + Invoice PDF + barcode
- Frontend: React + TypeScript + Vite + Tailwind + Framer Motion
- Docker Compose to run backend, frontend, db, redis

**Next steps**
1. Fill SECRET_KEY and Stripe keys in backend/.env
2. Build images and run with `docker-compose up --build`
3. Use provided API endpoints and frontend pages as starting point.
